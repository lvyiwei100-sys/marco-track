# marco-track
| 维度     | 代表变量                        | 作用           |
| ------ | --------------------------- | ------------ |
| 增长     | 工业产出、零售销售、CFNAI、消费者信心       | 判断需求斜率       |
| 通胀     | CPI、核心CPI、PCE、核心PCE、10Y通胀预期 | 判断通胀压力和粘性    |
| 就业     | 非农三个月均值、失业率、初请、JOLTS        | 判断劳动力市场拐点    |
| 金融条件   | 10Y-3M、10Y-2Y、高收益债利差、NFCI   | 判断衰退/信用压力    |
| 政策与流动性 | 联邦基金利率、M2、联储资产负债表           | 判断政策约束与流动性背景 |
